# План разработки

Сроки рассчитаны на работу по вечерам и выходным вдвоём с Claude. Главное правило: **не переходить к следующему этапу, пока текущий не проверен на живых друзьях.**

## Этап 0 — Старт (неделя 1) ✅ частично готово

- [x] Идея, дизайн-документ, стратегия по ассетам
- [x] Скелет проекта Godot: меню, хост/подключение, тестовый зал, вор с камерой
- [x] Ядро: мольберт, экран рисования, синхронизация мазков по сети, оценка подделки, подмена картины
- [x] Автотесты (одиночный и сетевой)
- [ ] Перенести проект на ноутбук, запустить, побегать вдвоём (2 окна) — см. README
- [ ] Создать отдельный приватный репозиторий `poddelka` на GitHub

## Этап 1 — «Смешно ли это?» (недели 2–5)

Цель — **один полностью играбельный раунд в грейбоксе**, плейтест с 2–3 друзьями.

- [ ] Охранник: патруль по точкам, конус зрения, шкала подозрения, реакция на шум (только на хосте)
- [ ] Проверка подделки охранником при проходе мимо (через `ForgeryJudge`)
- [ ] Снять и повесить картину (взаимодействие), оригинал как физический предмет, переноска (вдвоём для больших рам)
- [ ] Фургон: зона победы, экран итогов (процент, время, деньги)
- [ ] Тревога → таймер побега → поимка (рэгдолл), «обезьянник» и спасение
- [ ] 2 гаджета: банан и костюм статуи
- [ ] Переносной мольберт
- [ ] Простой звук: шаги, тревога, «шлёп» рэгдолла (плейсхолдеры Kenney)
- [ ] **Плейтест.** Записать, где смеялись, где скучали и где бесились. Решить: оставить, упростить или выкинуть.

## Этап 2 — Steam и стиль (недели 6–10)

- [ ] GodotSteam: лобби, приглашения, вход по приглашению (сначала App ID 480)
- [ ] Голосовой чат по близости
- [ ] **Арт-стиль, вертикальный срез:** одна комната, вор и охранник в финальном стиле. Палитра, тун-шейдер, обводка (см. 02_ASSETS.md)
- [ ] Модульный кит музея (Blender-скрипты Claude) + база персонажа + анимации
- [ ] Настоящие картины из открытых коллекций
- [ ] **Steamworks:** регистрация ($100), создание страницы. Капсула от художника, 5 скриншотов, гифки. **Страница должна открыться как можно раньше: вишлисты копятся месяцами**
- [ ] Начать публиковать клипы (TikTok, Shorts, Reddit r/IndieGaming и r/CoopGaming, Twitter/X): кривые подделки — идеальный контент

## Этап 3 — Контент (недели 11–18)

- [ ] Убежище: доска заказов, магазин, галерея позора (сохранение подделок)
- [ ] Газета-итог с кнопкой «Сохранить картинку»
- [ ] 3 музея из плана (провинциальный, современного искусства, особняк)
- [ ] 6–8 гаджетов, косметика (шапки, маски, комбинезоны)
- [ ] Эксперт-NPC (проверка вблизи)
- [ ] Настройки (графика, звук, чувствительность, раскладка), локализация RU/EN
- [ ] Регулярные закрытые плейтесты (Steam Playtest или ключи друзьям)

## Этап 4 — Демо и Next Fest (недели 19–24)

- [ ] Бесплатная демо-версия (первый музей) в Steam
- [ ] Участие в **Steam Next Fest**. Фестивали обычно проходят в феврале, июне и октябре — точные даты и сроки регистрации смотри в Steamworks заранее
- [ ] Рассылка ключей стримерам и ютуберам, которые играют в кооп-игры (маленьким и средним — они охотнее отвечают)
- [ ] Трейлер на 30–60 секунд
- [ ] Финальный музей, баланс, полировка, исправление багов

## Этап 5 — Релиз и после

- [ ] Релиз со скидкой 10–20%
- [ ] Первые 2 недели — быстрые патчи по отзывам
- [ ] Бесплатное обновление с новым музеем через 1–2 месяца (возвращает игроков и стримеров)
- [ ] Steam Deck: проверка и бейдж «Verified»
