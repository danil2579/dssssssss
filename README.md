# TryOn 3D — виртуальная примерочная

Открывай на айфоне как обычный сайт. Крутишь 3D-аватара → грузишь фото образа → видишь, как оно на тебе сидит. Перед заказом.

## Как запустить

### Локально
Любой статический сервер. Например:
```bash
cd dssssssss
python3 -m http.server 8080
# открой http://<ip-компа>:8080 с айфона (в одной Wi-Fi)
```

### Деплой на GitHub Pages (бесплатно, HTTPS, работает на iPhone сразу)
1. В репозитории: **Settings → Pages → Source: Deploy from branch → `main` / root**.
2. После билда откроется ссылка вида `https://<user>.github.io/<repo>/`.
3. На айфоне: открой ссылку в Safari → кнопка «Поделиться» → **«На экран «Домой»»**. Иконка появится как приложение.

Альтернативы: Vercel, Netlify, Cloudflare Pages — дропни папку, получишь HTTPS.

## Что уже работает

- 3D-аватар (пока заглушка-манекен) + свет/тени, крутится пальцем.
- Загрузка фото образа (одной кнопкой).
- Образ накладывается изогнутой «тканью» на торс — виден с любого ракурса.
- Автоматическое удаление фона (хромакей по углам картинки) — работает для плоских фото на белом/сером.
- Ползунки: высота, размер, облегание, прозрачность фона.
- PWA: «На экран «Домой»» → запускается без адресной строки.
- Service Worker: кэш, работает и офлайн после первой загрузки.

## Что тебе нужно сделать

### 1. Загрузить свои фото в аватар
В нижней панели → раздел «Мой 3D-аватар» → 3 слота: **Спереди / Сбоку / Сзади**.
- Фон уже вырезан или ровный белый — хромакей сам уберёт его.
- Фигура во весь рост, поза А (руки чуть разведены).
- Один и тот же масштаб у всех 3 фото — иначе аватар «прыгает» при повороте.

Под капотом: твои фото становятся 4 плоскостями в крестообразной расстановке (фронт, левый бок = зеркало правого, спина). При вращении камеры ты видишь ту сторону, что обращена к тебе. Это **billboard-аватар** — не настоящая mesh-модель, но узнаваемый «ты в 3D», и образы отлично кладутся поверх.

### 2. Загрузить образ
«Загрузить образ» → выбери фото шмотки. Подкрути ползунками.

### 3. Если хочешь настоящую 3D-mesh модель
Нужно **30–50 перекрывающихся фото** по кругу (а не 3) — тогда photogrammetry соберёт mesh. Готовый `.glb` грузится в нижний слот «Загрузить .glb / .gltf».

## Что ещё можно улучшить (следующие итерации)

- **Честная примерка одежды** — сейчас это оверлей на торс. Правильно: сегментация одежды (например, `BodyPix` / `MediaPipe Selfie Segmentation` на фото → cloth mesh с симуляцией). Можно подключить, скажи — сделаю.
- **AR-режим** (`<model-viewer>` с `ar` атрибутом) — смотреть аватара в комнате через камеру айфона.
- **Фото-сессия**: кнопка «скриншот» — сохранять примерки в галерею.
- **Несколько образов одновременно** (верх/низ/обувь).
- **Замеры**: ввёл рост/обхваты → манекен подгоняется под пропорции.

## Структура

```
index.html              — обёртка, мета для iOS, importmap для Three.js с CDN
styles.css              — mobile-first UI, bottom-sheet
app.js                  — сцена, манекен, загрузка образа, shader для хромакея
manifest.webmanifest    — PWA (install на iPhone)
sw.js                   — service worker (офлайн-кэш)
icons/                  — PWA-иконки
```

Никакой сборки — чистый ES-модуль. Three.js тянется с `unpkg` по importmap.
